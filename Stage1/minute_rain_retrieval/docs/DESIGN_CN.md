# 设计说明

## 设计目标

系统用一个雨量计采样时刻之前一分钟内的全部有效卫星观测，反演该分钟累计降雨量。样本单位固定为一分钟，而不是单个PHY点或完整卫星过境，因此预测值不会随一分钟内采样点数量线性累加。

采用变长Transformer编码器的原因是：每分钟内PHY点数量和卫星数量不固定，模型需要在统一输出一个标量的同时建模点间时序、卫星身份及多源特征关系。当前实现是小型专用模型，不依赖大语言模型。

## 核心模块

| 模块 | 文件 | 责任 |
|---|---|---|
| 数据构建 | `data_flow.py`, `build_dataset.py` | 读取SQLite、清洗、同卫星位置匹配、分钟窗口构造和数据划分 |
| 数据封装 | `dataset.py` | 仅用训练集拟合标准化、卫星索引和dry baseline；变长序列截断与批处理补齐 |
| 模型 | `model.py` | 数值投影、卫星嵌入、summary token、3层Transformer编码器及分类/雨量双头 |
| 训练评估 | `train.py` | 动态无雨下采样、联合损失、余弦学习率、早停、checkpoint和预测表导出 |
| 工作流 | `run_workflow.py` | 构建或复用数据、归档full/train/val/test、训练并记录manifest |
| 在线输入 | `terminal_io.py` | 001旧协议、002/003新协议和链路域Z-score适配 |
| 在线服务 | `service.py` | 三模型加载、分钟推理、视觉标签刷新、历史回填和后台轮询 |
| API与页面 | `rainfall_dashboard/app.py` | FastAPI接口、ECharts页面、历史查询和链路可靠性展示 |
| 历史存储 | `lora_moe/history/rain_retrieval.py` | SQLite结果读写；表名因兼容旧库仍为`rain_retrieval_passes` |

## 离线主流程

1. 从SQLite读取001终端PHY、位置、温湿度气压和雨量计记录。
2. 对位置记录计算斜距、仰角、方位角正弦和余弦。
3. 按相同卫星ID、最近时间且不超过5秒对齐PHY与位置；地面气象默认按5秒最近邻对齐。
4. 对每个雨量计锚点 `g` 截取 `(g-60 s, g]`。窗口至少有3个有效PHY点才构成样本。
5. 标签为雨量计字段 `rainfall * 0.1`，即该窗口一分钟累计降雨量，单位mm。
6. 将最近10分钟内的视觉分类概率附到窗口各点；没有匹配图像时四维视觉特征为0。
7. 保存16维基础特征：链路4维、几何4维、地面气象3维、视觉4维、相对时间1维。
8. 数据划分后，仅从训练集无雨分钟估计每颗卫星4维链路dry baseline；未知卫星使用训练集全局均值。链路差分加入后模型输入为20维。
9. 数值特征投影到160维，卫星ID嵌入为32维，拼接后映射为192维token。summary token与点token进入3层、8头Transformer编码器。
10. 分类头输出降雨logit，雨量头用Softplus输出条件雨量，最终预测为 `sigmoid(logit) * conditional_amount`。

训练损失由全样本Smooth L1、仅有雨样本的对数雨量Smooth L1和带`pos_weight`的降雨BCE组成。强降雨样本可加权；默认按验证集balanced MAE保存最优checkpoint。训练集可动态限制无雨/有雨比，验证集与测试集不下采样。

## 在线主流程

1. 后台视觉worker扫描新照片并更新天气概率CSV。
2. 服务从实时库和恢复备份读取三终端链路。001使用旧协议；002/003联合BB和RSSI表，并用固定Z-score适配器映射到001链路特征域。
3. 每个雨量计锚点构造前一分钟窗口。001优先使用完整位置模型，缺位置时使用无位置回退模型；002/003使用迁移权重。
4. checkpoint中保存的标准化、卫星映射和dry baseline被原样用于在线预处理。
5. 推理结果写入统一历史SQLite，FastAPI查询优先读取已物化历史；当天数据由后台worker增量更新。
6. 页面展示分钟真实值、各终端预测值、累计值、终端一致性及链路可靠性分析。

## SNR质量设计

`-10 dB`用于界面标识强链路点，但不是当前部署数据的硬过滤条件。严格使用该门槛只保留38.0%的有雨样本，且18个大于1 mm/min的强降雨窗口仅保留2个。代码支持`none`、`hard_mask`和`soft_gate`，当前部署配置为`none`；归档另提供`-10 dB`和`-25 dB`数据视图用于后续消融。
