# 原始链路可靠性与断链分析

本目录以工控机清洗前数据库和原始 CSV 为唯一 PHY/位置事实来源，雨量计数据库仅用于时间对齐后的降雨分层。

```bash
cd /home/wdz/BT/Stage1/link_reliability_analysis
python3 analyze_raw_link_reliability.py
python3 export_analysis_summary_excel.py
python3 export_monthly_phy_excel.py
```

数据拼接规则：清洗前数据库使用至对应表的最大时间，原始 CSV 仅保留严格晚于该时间的记录，避免两个来源重叠。原始 CSV 不保证按时间排序，因此程序会扫描全文件。所有产物均记录源路径、文件 SHA-256、切分时间和清洗规则路径。

程序同时输出两种会话内缺样率：终端 001 标称 2 秒口径，以及按各月同星会话实测中位采样周期校正的口径。独立位置流仅用于形成地平线以上的可见机会和重访统计；由于缺少调度日志，“可见但无 PHY”不直接计为断链。`4294967295` 单独解释为“未锁定有效卫星”，不与字段异常混合。雨相关、疑似干扰或终端异常均为统计关联诊断，不构成单次事件的因果证明。

主要产物包括逐会话诊断、逐次卫星接续空窗、月度连续覆盖趋势、雨强分层、原始质量及其雨强关联、逐星月度统计、溯源 JSON 和每月原始 PHY Excel。`inter_satellite_gaps.csv` 保留前后卫星 ID、直接相邻会话间隔、考虑所有重叠卫星后的真实全网空窗、同期雨强及长空窗标记。Excel 保留原始字段及来源记录 ID，不修改原始文件。
